Analysis helpers
================

This folder is for lightweight scripts and notebooks to summarize runs and prepare visuals.

Suggested plots (see RUNS_OVERVIEW.md for context):
- IP licensing: welfare by regime; profit distribution with adversarial sellers.
- Internal market: budgets by department over quarters; risky features and outages.
- Shapley: final allocations vs reference; L1 distance to Shapley by condition.
- Vickrey: valuations vs bids; revenue by condition.
